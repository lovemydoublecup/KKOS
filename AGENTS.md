# AI Agent Guide for KKOS v5.2 Unified Bundle

## What this repository is

- A Windows-native C++ simulation engine for KKOS in `src/kkos_v520_unified.cpp`.
- A Python-based AI workspace in `odysseus/` that powers the Odysseus web app.
- A unified developer workflow driven by `BUILD.bat`, `LAUNCH.ps1`, and the generated `.vscode/` configs.
- Container support for Odysseus via `docker-compose.yml` and GPU profiles.

## Primary developer workflows

- `BUILD.bat` from the repo root is the main build script.
  - `BUILD.bat` = full build (KKOS + Odysseus)
  - `BUILD.bat kkos` = compile C++ engine only
  - `BUILD.bat odysseus` = Python/Odysseus setup only
  - `BUILD.bat run` = build then launch both systems
  - `BUILD.bat diag` = capture compiler/diagnostic environment details
  - `BUILD.bat vscode` = generate/update `.vscode/` launch/tasks/settings
  - `BUILD.bat clean` = archive legacy files and clear `obj/`
- `LAUNCH.ps1` starts Odysseus and/or KKOS engine with PowerShell switches.
- `start-all.bat`, `start-kkos-only.bat`, `start-odysseus-only.bat` execute standard runtime workflows.

## Key source locations

- `src/kkos_v520_unified.cpp` — canonical C++ entrypoint for KKOS.
- `Single-Exe-1.0.0/raylib-5.5/src/` — vendored raylib C sources used by the engine.
- `odysseus/` — Python app and AI workspace.
  - `odysseus/requirements.txt` — core Python dependencies.
  - `odysseus/requirements-optional.txt` — optional packages.
  - `odysseus/setup.py` — project setup for the Odysseus app.
- `docker-compose.yml` — unified compose for Odysseus; GPU profiles in `docker-compose.gpu-nvidia.yml` and `docker-compose.gpu-amd.yml`.
- `.vscode/` is generated by `BUILD.bat vscode` and contains C++ debug tooling config.

## Environment expectations

- Builds assume Windows + MSYS2 UCRT64.
- Canonical compiler path: `C:\msys64\mysys64_new\ucrt64\bin\g++.exe`; fallback `C:\msys64\ucrt64\bin\g++.exe`.
- `BUILD.bat` changes to its own directory before running, so tasks must execute from the repo root.
- Odysseus requires Python 3.11+ and creates a `odysseus/venv` virtual environment.
- C++ runtime depends on UCRT64 DLLs (`libstdc++-6.dll`, `libgcc_s_seh-1.dll`, `libwinpthread-1.dll`) being available on PATH or alongside `bin/kkos_v520.exe`.

## Practical guidance for AI agents

- Use `BUILD.bat` / `LAUNCH.ps1` as the canonical commands for build and run validation.
- Prefer editing `src/` for KKOS engine changes and `odysseus/` for Python/Ai workspace changes.
- Do not assume the repo is a standard Node or Python app only; it is a mixed C++ + Python project with Windows-first tooling.
- Avoid broad changes to generated `.vscode/` config unless necessary; these files are created by `BUILD.bat vscode`.
- If a task touches third-party code under `Single-Exe-1.0.0/`, treat it as vendored library source and verify compatibility carefully.
- Ignore `subprojects/` by default unless the task explicitly names one of those embedded repositories.
