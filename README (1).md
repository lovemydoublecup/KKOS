## What's in this integration

This package consolidates 20 separate scripts into a clean, minimal set with no overlapping responsibilities.

| New File | Replaces |
|---|---|
| `BUILD.bat` | `build-windows.bat`, `build-all-steps.bat`, `build-kkos-complete.bat`, `build_windows.bat` |
| `LAUNCH.ps1` | `launch-windows.ps1`, `build_and_run.ps1` |
| `docker-compose.yml` | `docker-compose.yml`, `docker-compose_gpu-nvidia.yml`, `docker-compose_gpu-amd.yml` |
| `UPDATE.bat` | `update_windows.bat` |
| `install-gdb.bat` | `install_gdb.bat`, `install_gdb_proper.bat` |
| `CLEAN.bat` | `cleanup.bat` |
| `start-all.bat` *(generated)* | `start-all.bat`, `KKOS.bat`, `start-all-steps.bat` |
| `start-kkos-only.bat` *(generated)* | `start-kkos-only.bat` |
| `start-odysseus-only.bat` *(generated)* | `start-odysseus-only.bat` |

The `KKOS_Installer.bat` remains unchanged — it handles system-level installation to `C:\Program Files\KKOS` and is self-contained.

## Prerequisites

- **MSYS2 UCRT64** with `mingw-w64-ucrt-x86_64-gcc` (for KKOS C++ build)
  - Default path: `C:\msys64\mysys64_new\ucrt64` or `C:\msys64\ucrt64`
  - Install: https://www.msys2.org/
- **Python 3.11+** (for Odysseus)
  - Install: https://www.python.org/downloads/
- **Docker Desktop** (for containerized Odysseus only)
- **Git for Windows** (optional, for full Cookbook/agent-shell features)

Install GDB (for debugging): `install-gdb.bat`

## Quick Start — Native Windows

### Full build + setup (first time)
```bat
BUILD.bat
```
Compiles KKOS C++ engine, creates Odysseus Python venv, installs dependencies, writes launcher scripts.

### Start everything
```bat
start-all.bat
```
Opens KKOS engine in a separate window, starts Odysseus at http://127.0.0.1:7000.

### Other BUILD.bat modes
```bat
BUILD.bat kkos        # KKOS C++ only — skip Odysseus
BUILD.bat odysseus    # Odysseus Python setup only — skip C++ build
BUILD.bat run         # Build then immediately launch both
BUILD.bat clean       # Archive legacy files, clear obj\
```

### PowerShell (advanced)
```powershell
# Start Odysseus only (no rebuild)
powershell -ExecutionPolicy Bypass -File .\LAUNCH.ps1

# Build KKOS + launch both
powershell -ExecutionPolicy Bypass -File .\LAUNCH.ps1 -Build

# KKOS engine only
powershell -ExecutionPolicy Bypass -File .\LAUNCH.ps1 -KKOSOnly

# Custom port / LAN binding
powershell -ExecutionPolicy Bypass -File .\LAUNCH.ps1 -Port 8080 -BindHost 0.0.0.0
```

## Quick Start — Docker

### CPU (default)
```bash
docker compose up -d
```

### NVIDIA GPU
```bash
docker compose --profile nvidia up -d
```
Requires NVIDIA Container Toolkit on host.

### AMD ROCm GPU
```bash
docker compose --profile amd up -d
```
Requires ROCm drivers; host user must be in `video` and `render` groups.
Set `RENDER_GID` in `.env` if your render group id differs from the default.

### Stack-management UIs (Portainer, Coolify)
These tools often don't support compose profiles. Use the standalone GPU files from the original release:
- `docker-compose_gpu-nvidia.yml`
- `docker-compose_gpu-amd.yml`

### Update Docker deployment
```bat
UPDATE.bat
```

## Services & Ports

| Service | Default URL | Notes |
|---|---|---|
| Odysseus | http://127.0.0.1:7000 | AI workspace, FastAPI |
| SearXNG | http://127.0.0.1:8080 | Private search, internal only |
| ChromaDB | http://127.0.0.1:8100 | Vector store, internal only |
| ntfy | http://127.0.0.1:8091 | Push notifications |

All bind to `127.0.0.1` by default. Override via `.env`:
```
APP_BIND=0.0.0.0
APP_PORT=7000
```

## Environment Variables (.env)

Copy `.env.example` to `.env` and fill in values:

```env
# LLM backends
LLM_HOST=localhost
OPENAI_API_KEY=
OLLAMA_BASE_URL=http://host.docker.internal:11434

# Auth
ODYSSEUS_ADMIN_USER=admin
ODYSSEUS_ADMIN_PASSWORD=

# Search APIs (optional)
TAVILY_API_KEY=
GOOGLE_API_KEY=
GOOGLE_PSE_CX=

# Container user (match your host uid/gid)
PUID=1000
PGID=1000
```

## Compiler Notes

`BUILD.bat` and `LAUNCH.ps1` resolve compilers in this order:

1. **MSYS2 UCRT64** at `C:\msys64\mysys64_new\ucrt64` (project default)
2. **MSYS2 UCRT64** at `C:\msys64\ucrt64` (canonical fallback)
3. **System `g++`** on PATH (MinGW, Cygwin)
4. **MSVC `cl.exe`** (Visual Studio Build Tools) — `.bat` only

If RAM is below 800 MB free, LTO (`-flto`) is automatically disabled.

## Debugging

Install GDB:
```bat
install-gdb.bat
```
Then debug:
```bat
C:\msys64\mysys64_new\ucrt64\bin\gdb.exe bin\kkos_v520.exe
```
Or use RenderDoc (included as `RenderDoc_1_31_64.msi`) for GPU frame capture.
